Amplify notes:

    - Our setup is only compatible with amplify v0.1.x (0.1.45 is ok).
    - Must be installed using "npm install -g @aws-amplify/cli@0.1.45"
    - If running from a different nvm version, also paths in file amplify -> .config -> project-config.json must be updated accordingly
    - The region can be changed using "aws configure" or editing the file ~/.aws/config 
    - To correctly push a new auth file amplify -> backend -> auth -> cognito -> cognito cloudformation must be edited 
        - replacing node6.10 with node12.x (in Ireland)
    - To import/update the user pool use cbr command (see above)

TO INSTALL UNDER WINDOWS 10:

1) Upgrade Windows 10 to release 2004
2) Follow the guide to properly install WSL2: https://docs.microsoft.com/it-it/windows/wsl/install-win10#update-to-wsl-2  
3) Install Ubuntu-20.04 from the app store
4) Open an Ubuntu terminal
5) Follow the guide here to install node: https://docs.microsoft.com/en-us/windows/nodejs/setup-on-wsl2
6) npm install -g @angular/cli
7) git clone https://github.com/nikapov/fuse-angular.git
8) cd fuse-angular
9) npm install  
10) npm run build
11) install Remote - WSL plugin under VS Code
12) code .
13) a visual studio code window should appear, open a terminal that should be a Linux terminal
14) ng serve
